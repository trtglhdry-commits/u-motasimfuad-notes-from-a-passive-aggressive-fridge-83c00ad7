One funny passive-aggressive note a smart fridge leaves for its owner.

> The leftovers from Tuesday have applied for permanent residency. I approved the application — someone in this house has to commit to something.

## How it works

`main.ts` (Node, stdlib only) writes the single-line note to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The output is deterministic — no randomness, no network, no clock — and a runtime guard refuses to write anything that would break the 1–200 character single-line gate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
